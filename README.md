# Ley 6/2022 Chatbot Documentation

## Introduction
This chatbot is designed to provide information related to Ley 6/2022, which addresses climate change and energy transition in the context of public policy.

## Features
- **Information Retrieval:** Users can query information about various aspects of Ley 6/2022.
- **Interactive Q&A:** The chatbot can answer frequently asked questions regarding implementation and guidelines.
- **Updates and News:** Stay informed about the latest developments regarding Ley 6/2022.

## Setup Instructions
To set up the chatbot, follow these steps:
1. Clone the repository: `git clone <repository-url>`
2. Install the required dependencies: `pip install -r requirements.txt`
3. Run the chatbot: `python app.py`

## Usage
Users can interact with the chatbot via a web interface or a messaging application. Simply type in your question or request and await a response.
